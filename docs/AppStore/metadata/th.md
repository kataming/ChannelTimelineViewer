## 説明（Description）
<!-- 2252 / 4000 文字 -->

```
Channel Timeline Viewer ช่วยให้คุณดูช่อง YouTube ตั้งแต่ต้นโดยไม่หลงว่าดูถึงไหนแล้ว

ไล่ดูช่องตั้งแต่วิดีโอที่เก่าที่สุด ติดตามว่าดูอะไรไปแล้ว เล่นต่อจากตำแหน่งเดิมได้อย่างแม่นยำ และจดบันทึกไปพร้อมกัน คลังวิดีโอ คอร์สเรียน และซีรีส์ยาวๆ จะเรียงลำดับอยู่เสมอ

เหมาะสำหรับใคร
• ผู้ที่เรียนรู้จากบทสอน การบรรยาย คอร์สเรียน ช่องการศึกษา และซีรีส์ยาวๆ บน YouTube
• ทุกคนที่อยากไล่ดูวิดีโอเก่าๆ ของช่องให้ครบ
• ผู้ชมที่อยากรู้ว่าดูไปถึงตรงไหนแล้วอย่างแม่นยำ
• เจ้าของช่องที่อยากให้ผู้ชมดูวิดีโอเก่าๆ ตามลำดับ

ฟีเจอร์หลัก
• วาง URL ของช่อง หรือแชร์วิดีโอหรือช่องจากแอป YouTube หรือ Safari
• แสดงวิดีโอแบบเก่าสุดก่อน (หรือใหม่สุดก่อน)
• ความคืบหน้าแยกตามช่อง: จำนวนที่ดูแล้ว เปอร์เซ็นต์ แถบความคืบหน้า
• "ถัดไป / ดูต่อ" พาคุณกลับไปยังจุดที่หยุดไว้ได้ทันที
• เล่นต่อจากวินาทีที่คุณหยุดไว้พอดี
• เล่นอัตโนมัติไปยังวิดีโอถัดไปในรายการ (เปิดไว้เป็นค่าเริ่มต้น และปิดได้ทุกเมื่อ)
• เล่นซ้ำวิดีโอเดียวหรือเล่นซ้ำทั้งหมด
• ทำเครื่องหมายวิดีโอว่าดูแล้วหรือข้าม เล่นเฉพาะที่ยังไม่ได้ดู
• ตัวกรอง: ทั้งหมด / ยังไม่ได้ดู / ดูแล้ว
• ค้นหาภายในช่องเพื่อกรองวิดีโอตามชื่อ
• บันทึกสำหรับแต่ละวิดีโอ ใช้สำหรับการเรียนหรือการดูซีรีส์
• ควบคุมความเร็วการเล่นและคำบรรยายได้จากภายนอกเพลเยอร์
• แสดงตำแหน่งเป็น "27 กุมภาพันธ์ 2569 (1,034 / 3,500)"
• ปุ่มนำทางห้าปุ่ม — แรกสุด ก่อนหน้า เลิกทำ ถัดไป สุดท้าย — ปุ่มเลิกทำจะคืนทั้งวิดีโอและตำแหน่งที่คุณอยู่
• ช่องที่เคยเปิดจะโหลดได้ทันทีจากรายการที่บันทึกไว้

การเล่นวิดีโอ
วิดีโอเล่นในเพลเยอร์แบบฝังอย่างเป็นทางการของ YouTube (IFrame Player)

ฟรีและ Pro
บันทึกได้ฟรีหนึ่งช่อง ภายในช่องนั้นทุกอย่างใช้ได้ไม่จำกัด: การเรียงลำดับ การติดตามที่ดูแล้ว การเล่นต่อ ปุ่มข้ามไปยังวิดีโอ บันทึก ความคืบหน้า และการเล่นในเพลเยอร์ทางการ
คุณเปลี่ยนไปใช้ช่องอื่นได้ฟรี แต่ประวัติการดู ความคืบหน้า และบันทึกของช่องเดิมจะถูกลบ
หากต้องการติดตามหลายช่องพร้อมกันและเก็บบันทึกทั้งหมดไว้ ให้ซื้อ Pro เป็นการซื้อครั้งเดียว ไม่ใช่การสมัครสมาชิก

โปรดทราบ
• แอปนี้ไม่ใช่แอป YouTube อย่างเป็นทางการ
• แอปนี้ไม่ดาวน์โหลดวิดีโอ ไม่บล็อกโฆษณา และไม่เล่นในเบื้องหลัง
• รายการวิดีโอได้มาจาก YouTube Data API v3
• เล่นอัตโนมัติเปิดไว้เป็นค่าเริ่มต้น แต่จะไปยังวิดีโอถัดไปในรายการที่คุณเปิดอยู่เท่านั้น และปิดได้ทุกเมื่อที่หน้าจอเพลเยอร์
• เวอร์ชันฟรีจะแสดงโฆษณา Pro เป็นการซื้อครั้งเดียวที่ไม่มีโฆษณา ไม่มีการสมัครสมาชิก

YouTube เป็นเครื่องหมายการค้าของ Google LLC
```
