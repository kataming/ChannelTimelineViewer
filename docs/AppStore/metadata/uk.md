## 説明（Description）
<!-- 2737 / 4000 文字 -->

```
Channel Timeline Viewer допомагає дивитися канали YouTube від самого початку й не губити місце, де ви зупинилися.

Переглядайте канал, починаючи з найстаріших відео, відстежуйте переглянуте, продовжуйте з точної позиції відтворення й робіть нотатки по ходу. Архіви, курси та довгі серії залишаються по порядку.

ДЛЯ КОГО
• Для тих, хто навчається за уроками, лекціями, курсами, освітніми каналами й довгими серіями на YouTube
• Для тих, хто хоче надолужити старі відео каналу
• Для глядачів, які хочуть точно знати, докуди додивилися
• Для авторів каналів, які хочуть, щоб глядачі дивилися їхні старі відео по порядку

ОСНОВНІ ФУНКЦІЇ
• Вставте URL-адресу каналу або поділіться відео чи каналом із застосунку YouTube або Safari
• Відео по порядку: спочатку старі (або спочатку нові)
• Прогрес для кожного каналу: кількість переглянутих, відсоток, індикатор прогресу
• «Далі / Продовжити» одразу повертає туди, де ви зупинилися
• Продовження з тієї самої секунди, на якій ви зупинилися
• Автовідтворення наступного відео зі списку (увімкнено за замовчуванням, можна вимкнути будь-коли)
• Повтор одного відео або всіх
• Позначайте відео як переглянуті або для пропуску; відтворюйте лише непереглянуті
• Фільтри: усі / непереглянуті / переглянуті
• Пошук у межах каналу: добір відео за назвою
• Нотатки до кожного відео — для навчання чи перегляду серій
• Швидкість відтворення й субтитри керуються поза плеєром
• Позиція відображається як «27 лютого 2026 р. (1 034 / 3 500)»
• П’ять кнопок навігації — перше, назад, скасувати, далі, останнє; «Скасувати» повертає і відео, і позицію, на якій ви були
• Канали, які ви вже відкривали, миттєво завантажуються зі збереженого списку

ВІДТВОРЕННЯ
Відео відтворюються в офіційному вбудованому плеєрі YouTube (IFrame Player).

БЕЗКОШТОВНО І PRO
Один канал можна зберегти безкоштовно. У межах цього каналу все працює без обмежень: сортування, позначки перегляду, продовження, кнопки переходу, нотатки, прогрес і відтворення в офіційному плеєрі.
Канал можна безкоштовно замінити іншим, але тоді історія переглядів, прогрес і нотатки попереднього каналу видаляються.
Щоб стежити за кількома каналами одночасно й зберігати всі записи, придбайте Pro. Це одноразова покупка, а не підписка.

ЗВЕРНІТЬ УВАГУ
• Цей застосунок не є офіційним застосунком YouTube.
• Він не завантажує відео, не блокує рекламу й не відтворює відео у фоновому режимі.
• Списки відео отримуються через YouTube Data API v3.
• Автовідтворення увімкнено за замовчуванням, але воно переходить лише до наступного відео у відкритому вами списку, і його можна вимкнути на екрані плеєра будь-коли.
• У безкоштовній версії показується реклама. Pro купується один раз, без реклами й без підписки.
```
