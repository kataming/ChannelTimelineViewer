# App 審査向けメモ（App Review Notes）

App Store Connect の「App Review Information > メモ（Notes）」に記載する内容の下書きです。

---

## アプリの目的
本アプリはチャンネルの投稿動画を公開日順（古い順）に整理し、順番に視聴しやすくする**視聴補助アプリ**です。
YouTube の代替アプリではありません。

## 動画一覧の取得
- 取得は **YouTube Data API v3**（公式 API）のみを使用します。スクレイピングは行いません。
- 取得する情報: videoId / タイトル / 説明 / 公開日 / サムネイルURL。

## 動画の再生
- 再生は **YouTube IFrame Player API（公式の埋め込みプレイヤー）** を WKWebView 上で表示します。
- 動画ファイルの取得・保存・独自プレイヤーでの再生は行いません。

## 自動再生について（任意機能・既定オフ）
- 自動再生は**ユーザーが選べる任意機能**で、**初期状態はオフ**です。
  既定では、動画の再生が終わると**そこで停止**し、「次の動画を再生」ボタンを表示します。
- 再生画面には「終了したら次を自動再生」トグルを常時表示しており、
  **ユーザーが明示的にオンにした場合のみ**、続けて再生します（設定は端末内に保存）。
- オンにした場合でも、進む先は**そのとき開いているチャンネル一覧の次の動画だけ**です。
  YouTube の関連動画・おすすめ動画へ遷移することはありません（埋め込みは `rel=0`）。
- **バックグラウンド再生は行いません**。アプリを閉じる・画面をロックすると再生も自動送りも停止します
  （`UIBackgroundModes` 未使用、`AVAudioSession`/`AVPlayer` 不使用）。
- 再生・自動送りのいずれも、表示しているのは**YouTube 公式の埋め込みプレイヤー**そのものです。
  動画のダウンロード・広告回避は行いません。

## 再生位置の保存について（続きから再生）
- 「続きから再生」のため、**公式プレイヤーが通知する再生位置（秒）だけ**を端末内に保存し、
  次に同じ動画を開いたときに公式プレイヤーの `startSeconds` に渡します。動画データは保存しません。
- 再生画面の「…」メニューからオフにでき、「最初から再生」で頭出しもできます。

## 共有シート（Share Extension）について
- 目的: チャンネルURLの手入力を不要にするための入力補助です。
- 拡張が行うのは **共有された URL / テキストから YouTube の URL を取り出し、
  カスタムURLスキーム（`channeltimelineviewer://share?url=...`）でメインアプリを開くことだけ**です。
- 拡張はネットワーク通信を行いません（YouTube API も呼びません）。API 取得・表示はすべてメインアプリ側です。
- 動画URLが共有された場合は、公式 API の `videos.list` で**投稿チャンネル**を特定し、
  そのチャンネルの動画一覧（公開日順）を開きます。動画の取得・保存は行いません。

## 行っていないこと（ポリシー順守）
- 動画のダウンロード: **なし**
- スクレイピング: **なし**（公式 API のみ）
- 独自プレイヤーでの動画再生: **なし**（公式 IFrame Player のみ）
- 広告の回避・ブロック: **なし**
- バックグラウンド再生: **なし**（`UIBackgroundModes` 未使用、`AVAudioSession`/`AVPlayer` 不使用）

> 補足: ソース上も `AVPlayer` / `AVAudioSession` / `UIBackgroundModes` / ダウンロード処理 / `.mp4` 取得 /
> スクレイピング用エンドポイントは含まれていません（再生は `loadHTMLString` による公式 IFrame 埋め込みのみ）。

## レビュー時のテスト手順
1. アプリ起動後、チャンネルURLを入力（例: 任意の公開チャンネルの `https://www.youtube.com/@handle`）。
2. 「動画を取得」をタップ → 投稿動画が公開日順（古い順）で一覧表示されます。
3. 動画をタップ → 公式埋め込みプレイヤーで再生。「前へ」「次へ」で移動できます。
4. 「ⓘ このアプリについて」に注意事項（公式アプリではない 等）を表示しています。
5. （任意）Safari で YouTube のチャンネル/動画ページを開き、共有ボタン → 「Channel Timeline Viewer」
   を選ぶと、同じ一覧画面が開きます。共有先に表示されない場合は、共有シートの「その他」から
   本アプリをオンにしてください。

## API キーについて（重要）
- 動画一覧の取得には YouTube Data API v3 の API キーが必要です。
- **提出ビルドには有効な API キーを含めてください**（`Resources/Config.plist` の `YOUTUBE_API_KEY`）。
  キーが無いと一覧取得時に「APIキーが設定されていません」と表示され、レビューで機能を確認できません。
- 必要に応じて、レビュー用のテスト手順・サンプルチャンネルURLをこのメモに追記してください。
