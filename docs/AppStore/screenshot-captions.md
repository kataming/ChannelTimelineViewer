# スクリーンショットのキャプション（7言語）

スクショに重ねる短い文言。カット構成は [`../screenshot-copy.md`](../screenshot-copy.md)、
撮影は `.github/workflows/ios-screenshots.yml`（入力 `languages` で言語ごとに撮れる）。

表現の注意（全言語共通）:

- 「YouTube を見るアプリ」ではなく **「チャンネル動画を時系列で整理・進捗管理する補助アプリ」**として書く。
- 「公式」と誤認させない。YouTube のロゴ・ブランド要素をキャプションに使わない。
- 実装していない機能（ダウンロード・広告なし・バックグラウンド再生）をうたわない。

各言語 6 カット。**見出し（1行）／サブ（1行）**の順。
