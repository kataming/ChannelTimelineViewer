## 詳しい説明（Full description）
<!-- 1134 / 4000 文字 -->

```
Channel Timeline Viewer は、チャンネルの投稿動画を「公開日順（古い順）」に並べ、最初の動画から順番に視聴・学習できるようにする視聴補助アプリです。解説シリーズ・講座・連載のように「最初から順に追いたい」動画に向いています。

■ こんな方に
・チャンネルの過去動画を最初から順番に見たい
・講座や講義を、教材のように進捗管理しながら見たい
・シリーズものを抜け漏れなく視聴したい

■ 主な機能
・チャンネルURLを入力、または YouTube アプリ／ブラウザの共有から開く
・投稿動画を公開日順（古い順／新しい順）に一覧表示
・チャンネルごとの進捗（視聴済み数／総数・進捗率・進捗バー）
・「次に見る／続きから」で、止めたところにすぐ戻れる
・前回停止した秒数からの続き再生
・終了後に一覧の次の動画へ進む自動再生（初期状態はオフ）
・リピート（1本／全体）
・視聴済み・スキップの管理、未視聴のみ再生
・フィルター（すべて／未視聴のみ／視聴済みのみ）
・動画ごとのメモ（学習・シリーズ視聴用）
・再生速度と字幕をプレイヤー外から操作
・「2026年2月27日（1,034 / 3,500）」のように一覧内の位置を表示
・移動ボタン5つ（最初へ／前へ／戻す／次へ／最後へ）。「戻す」は直前の動画と再生位置に復帰
・一度開いたチャンネルは保存した一覧からすぐ表示
・日本語・英語・中国語（簡体）・スペイン語・ドイツ語・フランス語・韓国語に対応

■ 再生について
動画の再生には YouTube 公式の埋め込みプレイヤー（IFrame Player）を使用します。

■ 無料でできること / Pro
無料で1つのチャンネルを保存できます。保存したチャンネルの中では、並べ替え・視聴済み管理・続きから再生・移動ボタン・メモ・進捗表示・公式プレイヤーでの再生を制限なく使えます。
複数のチャンネルを保存して、それぞれの進捗を管理したくなったときは Pro をご購入ください。買い切りで、サブスクリプションではありません。

■ ご注意
・本アプリは YouTube 公式アプリではありません。
・動画のダウンロード、広告回避、バックグラウンド再生は行いません。
・動画一覧の取得には YouTube Data API v3 を使用します。
・自動再生は初期状態でオフで、進むのは開いている一覧の次の動画だけです。
・アプリ内に広告はありません。サブスクリプションもありません（Pro は買い切りです）。
・視聴履歴・進捗・メモ・再生位置は端末内にのみ保存され、外部へ送信されません。

※ YouTube は Google LLC の商標です。
```
