## 詳しい説明（Full description）
<!-- 1354 / 4000 文字 -->

```
Channel Timeline Viewer는 YouTube 채널을 첫 영상부터 순서대로 볼 수 있게 도와주는 시청 보조 앱입니다.

업로드 영상을 게시일순(오래된 순)으로 정리하고, 어디까지 봤는지 기록하며, 멈춘 초부터 이어서 재생합니다. 영상마다 메모도 남길 수 있어 과거 영상·강의·장기 시리즈를 빠짐없이 따라갈 수 있습니다.

■ 이런 분께
・YouTube의 튜토리얼·강의·강좌로 공부하는 분
・채널의 과거 영상을 처음부터 정주행하고 싶은 분
・어디까지 봤는지 정확히 알고 싶은 분
・시청자가 과거 영상을 순서대로 보기를 바라는 채널 운영자
・어린 자녀와 선택한 채널 안에서 보고 싶은 보호자

■ 주요 기능
・채널 URL 입력, 또는 YouTube 앱·브라우저의 공유로 열기
・업로드 동영상을 게시일순(오래된 순／최신 순)으로 목록 표시
・채널별 진행률(시청 수／전체 수, 백분율, 진행 바)
・‘다음 시청／이어 보기’로 멈춘 곳으로 바로 이동
・마지막으로 멈춘 초부터 이어서 재생
・종료 후 목록의 다음 동영상으로 넘어가는 자동 재생(기본 켜짐, 언제든지 끌 수 있습니다)
・반복 재생(한 편／전체)
・시청함·건너뛰기 관리, 안 본 동영상만 재생
・필터(전체／안 본 것／시청한 것)
・동영상별 메모(학습·시리즈 시청용)
・재생 속도와 자막을 플레이어 밖에서 조작
・‘2026년 2월 27일 (1,034 / 3,500)’처럼 목록 내 위치 표시
・이동 버튼 5개(처음／이전／되돌리기／다음／마지막)
・한 번 연 채널은 저장된 목록에서 바로 표시
・한국어·영어·일본어·중국어(간체)·스페인어·독일어·프랑스어 지원

■ 재생에 대하여
동영상은 YouTube 공식 임베드 플레이어(IFrame Player)로 재생됩니다.

■ 무료와 Pro
무료로 채널 1개를 저장할 수 있습니다. 저장한 채널 안에서는 정렬, 시청 완료 관리, 이어 보기, 이동 버튼, 메모, 진행률 표시, 공식 플레이어 재생을 제한 없이 사용할 수 있습니다.
무료 상태에서 다른 채널로 교체할 수도 있지만, 그때 이전 채널의 시청 기록·진행 상황·메모가 삭제됩니다.
여러 채널을 기록을 남긴 채 함께 보려면 Pro를 구매하세요. 구독이 아닌 1회 구매입니다.

■ 유의 사항
・이 앱은 YouTube 공식 앱이 아닙니다.
・동영상 다운로드, 광고 차단, 백그라운드 재생을 하지 않습니다.
・동영상 목록은 YouTube Data API v3로 가져옵니다.
・자동 재생은 기본으로 켜져 있지만, 열어 둔 목록의 다음 동영상으로만 이동하며 재생 화면에서 언제든지 끌 수 있습니다.
・광고가 없고 구독도 없습니다(Pro는 1회 구매입니다).
・시청 기록·진행률·메모·재생 위치는 기기에만 저장됩니다.

※ YouTube는 Google LLC의 상표입니다.
```
