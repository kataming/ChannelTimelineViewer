## 詳しい説明（Full description）
<!-- 2890 / 4000 文字 -->

```
Channel Timeline Viewer помогает смотреть каналы YouTube с самого начала и не терять место, где вы остановились.

Просматривайте канал начиная с самых старых видео, отмечайте просмотренное, продолжайте с точной позиции воспроизведения и делайте заметки по ходу. Архивы, курсы и длинные серии остаются по порядку.

ДЛЯ КОГО
• Для тех, кто учится по урокам, лекциям, курсам, образовательным каналам и длинным сериям на YouTube
• Для тех, кто хочет наверстать старые видео канала
• Для зрителей, которые хотят точно знать, докуда досмотрели
• Для авторов каналов, которые хотят, чтобы зрители смотрели их старые видео по порядку

ОСНОВНЫЕ ФУНКЦИИ
• Вставьте URL канала или поделитесь видео либо каналом из приложения YouTube или браузера
• Видео по порядку: сначала старые (или сначала новые)
• Прогресс по каждому каналу: число просмотренных, процент, индикатор прогресса
• «Далее / Продолжить» сразу возвращает туда, где вы остановились
• Продолжение с той самой секунды, на которой вы остановились
• Автовоспроизведение следующего видео из списка (включено по умолчанию, можно выключить в любой момент)
• Повтор одного видео или всех
• Отмечайте видео как просмотренные или для пропуска; воспроизводите только непросмотренные
• Фильтры: все / непросмотренные / просмотренные
• Поиск внутри канала: отбор видео по названию
• Заметки к каждому видео — для учёбы или просмотра серий
• Скорость воспроизведения и субтитры управляются вне плеера
• Позиция отображается как «27 февраля 2026 г. (1 034 / 3 500)»
• Пять кнопок навигации — первое, назад, отменить, далее, последнее; «Отменить» возвращает и видео, и позицию, на которой вы были
• Каналы, которые вы уже открывали, мгновенно загружаются из сохранённого списка
• Доступно на 35 языках

ВОСПРОИЗВЕДЕНИЕ
Видео воспроизводятся в официальном встроенном плеере YouTube (IFrame Player).

БЕСПЛАТНО И PRO
Один канал можно сохранить бесплатно. Внутри этого канала всё работает без ограничений: сортировка, отметки о просмотре, продолжение, кнопки перехода, заметки, прогресс и воспроизведение в официальном плеере.
Канал можно бесплатно заменить другим, но при этом история просмотров, прогресс и заметки предыдущего канала удаляются.
Чтобы следить за несколькими каналами одновременно и сохранять все записи, купите Pro. Это разовая покупка, а не подписка.

ОБРАТИТЕ ВНИМАНИЕ
• Это приложение не является официальным приложением YouTube.
• Оно не скачивает видео, не блокирует рекламу и не воспроизводит видео в фоновом режиме.
• Списки видео получаются через YouTube Data API v3.
• Автовоспроизведение включено по умолчанию, но переходит только к следующему видео в открытом вами списке, и его можно выключить на экране плеера в любой момент.
• Без рекламы. И без подписок — Pro покупается один раз.
• История просмотров, прогресс, заметки и позиции воспроизведения хранятся на вашем устройстве.

YouTube является товарным знаком Google LLC.
```
