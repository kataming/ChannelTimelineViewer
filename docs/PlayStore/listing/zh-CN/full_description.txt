Channel Timeline Viewer 帮你从第一个视频开始看 YouTube 频道，不会忘记看到哪里。

按发布日期（从旧到新）浏览频道的投稿视频，记录看过的部分，从上次停下的秒数继续播放，还能为每个视频留下笔记。往期内容、课程和长期连载都保持顺序。

■ 适合谁
・用 YouTube 的教程、讲座、课程和教育频道学习的人
・想从头补看频道往期视频的人
・希望清楚知道自己看到第几集的观众
・希望观众按顺序看完往期视频的频道运营者
・想和孩子一起停留在所选频道里的家长

■ 主要功能
・输入频道网址，或从 YouTube 应用／浏览器分享打开
・按发布日期（从旧到新／从新到旧）列出投稿视频
・每个频道的进度（已观看数／总数、百分比、进度条）
・“接下来／继续”可直接回到上次停下的位置
・从上次停止的秒数继续播放
・自动播放列表中的下一个视频（默认开启，可随时关闭）
・重复播放（单个／全部）
・已观看与跳过状态管理，只播放未观看
・筛选（全部／仅未观看／仅已观看）
・每个视频的笔记（学习与连续观看用）
・在播放器之外调整播放速度与字幕
・以“2026年2月27日（1,034 / 3,500）”的形式显示在列表中的位置
・五个导航按钮（第一个／上一个／撤销／下一个／最后一个）
・打开过的频道会从已保存的列表立即显示
・支持简体中文、日语、英语、西班牙语、德语、法语、韩语

■ 关于播放
视频通过 YouTube 官方嵌入式播放器（IFrame Player）播放。

■ 免费版与 Pro
免费即可保存 1 个频道。在已保存的频道内，排序、已观看管理、继续播放、跳转按钮、备注、进度显示、官方播放器播放均无限制。
免费版也可以更换为其他频道，但更换时会删除原频道的已观看记录、进度和备注。
若想同时关注多个频道并保留所有记录，请购买 Pro。一次性买断，不是订阅。

■ 请注意
・本应用不是 YouTube 官方应用。
・不下载视频、不屏蔽广告、不进行后台播放。
・视频列表通过 YouTube Data API v3 获取。
・自动播放默认开启，但只会前进到你打开的列表中的下一个视频，并且可以在播放界面随时关闭。
・没有广告，也没有订阅（Pro 为一次性买断）。
