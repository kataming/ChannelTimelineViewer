Channel Timeline Viewer 会按发布日期（从旧到新）整理频道的投稿视频，让你从第一个视频开始，按顺序看完往期内容、课程或长期连载的系列，而不会忘记看到哪里。

■ 适合谁
・想从头补看频道往期视频的人
・像上课一样跟进讲座、课程的学习者
・希望清楚知道自己看到第几集的观众

■ 主要功能
・输入频道网址，或从 YouTube 应用／浏览器分享打开
・按发布日期（从旧到新／从新到旧）列出投稿视频
・每个频道的进度（已观看数／总数、百分比、进度条）
・“接下来／继续”可直接回到上次停下的位置
・从上次停止的秒数继续播放
・可选的自动播放下一个视频（默认关闭）
・重复播放（单个／全部）
・已观看与跳过状态管理，只播放未观看
・筛选（全部／仅未观看／仅已观看）
・每个视频的笔记（学习与连续观看用）
・在播放器之外调整播放速度与字幕
・以“2026年2月27日（1,034 / 3,500）”的形式显示在列表中的位置
・五个导航按钮（第一个／上一个／撤销／下一个／最后一个）
・打开过的频道会从已保存的列表立即显示
・支持简体中文、日语、英语、西班牙语、德语、法语、韩语

■ 关于播放
视频通过 YouTube 官方嵌入式播放器（IFrame Player）播放。

■ 请注意
・本应用不是 YouTube 官方应用。
・不下载视频、不屏蔽广告、不进行后台播放。
・视频列表通过 YouTube Data API v3 获取。
・自动播放默认关闭，且只会前进到你打开的列表中的下一个视频。
・没有应用内购买、订阅或广告。所有人使用的都是功能相同的同一个版本。
・观看记录、进度、笔记与播放位置仅保存在设备中。
