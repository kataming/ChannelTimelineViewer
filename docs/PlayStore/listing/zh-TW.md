## 詳しい説明（Full description）
<!-- 1079 / 4000 文字 -->

```
Channel Timeline Viewer 協助你從頭開始觀看 YouTube 頻道，不會忘記自己看到哪裡。

從最舊的上傳影片開始瀏覽頻道、記錄已觀看的影片、從確切的播放位置繼續播放，還能邊看邊寫筆記。過往影片、課程與長期連載系列都能保持順序。

適合這些人
• 透過 YouTube 教學影片、講座、課程、教育頻道和長期連載系列學習的人
• 想補看頻道過往影片的人
• 想確實知道自己看到哪裡的觀眾
• 希望觀眾依序看完自己舊影片的頻道經營者
• 想用更簡單的方式，讓年幼孩子只在一個選定頻道內觀看的家長

主要功能
• 貼上頻道網址，或從 YouTube App 或瀏覽器分享影片或頻道
• 上傳影片依由舊到新排列（也可由新到舊）
• 各頻道的進度：已觀看數量、百分比、進度條
• 「下一部／繼續」讓你直接回到上次停下的地方
• 從上次離開的那一秒繼續播放
• 自動播放清單中的下一部影片（預設為開啟，可隨時關閉）
• 單部重複或全部重複
• 將影片標記為已觀看或略過；只播放未觀看的影片
• 篩選：全部／未觀看／已觀看
• 頻道內搜尋，依標題篩選影片
• 每部影片都能寫筆記，方便學習或追系列
• 在播放器外控制播放速度與字幕
• 以「2026年2月27日（1,034 / 3,500）」的形式顯示目前位置
• 五個移動按鈕：第一部、上一部、復原、下一部、最後一部；「復原」會同時還原影片與你當時的播放位置
• 開啟過的頻道會從已儲存的清單中立即載入
• 支援 35 種語言

播放方式
影片在 YouTube 官方嵌入式播放器（IFrame Player）中播放。

免費版與 Pro
你可以免費儲存一個頻道。在該頻道內，所有功能都能不受限制地使用：排序、已觀看紀錄、繼續播放、移動按鈕、筆記、進度，以及在官方播放器中播放。
你也可以免費換成其他頻道，但這麼做會清除前一個頻道的觀看紀錄、進度與筆記。
若想同時追蹤多個頻道並保留所有紀錄，請購買 Pro。Pro 為一次購買，不是訂閱制。

注意事項
• 本 App 並非 YouTube 官方 App。
• 本 App 不會下載影片、封鎖廣告，也不會在背景播放。
• 影片清單是透過 YouTube Data API v3 取得。
• 自動播放預設為開啟，但只會前往你開啟的清單中的下一部影片，而且你隨時都能在播放畫面上將它關閉。
• 沒有廣告，也沒有訂閱制——Pro 為一次購買。
• 觀看紀錄、進度、筆記和播放位置都只保存在你的裝置上。

YouTube 是 Google LLC 的商標。
```
