# Android 版を実機で試す手順

`android/` のアプリを、GitHub Actions が作った APK で確認するための手順。
Google Play を通さず、APK を直接インストールする（サイドロード）。

---

## 0. 先に必要なもの: Android 用の API キー

**iOS 用のキーはそのまま使えません。** 理由は2つ。

- iOS 用キーには「iOS アプリ（Bundle ID）」の制限をかけているため、Android から呼ぶと 403 で弾かれる
- このリポジトリは Public で、**Actions の artifact は誰でもダウンロードできる**。
  APK の中身からキーは簡単に取り出せるので、公開する APK に入れてよいのは
  「Android アプリ制限つきのキー」だけ

### Android 用キーの作り方（Google Cloud Console）

1. https://console.cloud.google.com/ → 対象プロジェクト →「APIとサービス」→「認証情報」
2. 「認証情報を作成」→「APIキー」（iOS 用とは**別のキー**を作る）
3. 作成したキーを開き、**アプリケーションの制限**で「**Android アプリ**」を選ぶ
4. 「項目を追加」で次を登録する

   | 項目 | 値 |
   | --- | --- |
   | パッケージ名 | `com.deskflowlabs.channeltimelineviewer` |
   | SHA-1 証明書のフィンガープリント | `93:1F:B3:FE:72:80:3D:8C:A1:73:4E:7E:C1:B1:7D:EB:AA:77:2D:36` |

   ※ この SHA-1 は、リポジトリに置いてあるデバッグ用署名鍵（`android/app/debug.keystore`）のもの。
   デバッグ鍵は秘密情報ではないため、どの端末・CI でビルドしても同じ署名になるようにコミットしてある。
   Google Play で配布するときは、Play が管理する署名鍵の SHA-1 も追加する。

5. **APIの制限**で「キーを制限」→「YouTube Data API v3」だけにチェック → 保存
6. GitHub の Secret に登録する
   https://github.com/kataming/ChannelTimelineViewer/settings/secrets/actions
   → New repository secret → 名前 `YOUTUBE_API_KEY_ANDROID` → 作成したキー

Secret を登録したあとに Android Build を実行すると、その APK で動画一覧を取得できるようになる。
未登録のままでもアプリは起動し、画面の確認はできる（一覧の取得だけ「APIキーが設定されていません」になる）。

## 1. APK を手に入れる

### PC で取得してスマホへ送る（確実）

1. https://github.com/kataming/ChannelTimelineViewer/actions/workflows/android-build.yml
2. 一番上の成功した実行（緑のチェック）を開く
3. ページ下部の **Artifacts** にある **`android-debug-apk`** をクリック → zip がダウンロードされる
4. zip を展開すると `app-debug.apk` が出てくる
5. スマホへ渡す（USB ケーブル、Google ドライブ、自分宛てのメールなど。どれでもよい）

### スマホだけで取得する

1. スマホの Chrome で上記の Actions ページを開き、GitHub にログイン
2. 同じように `android-debug-apk` をタップしてダウンロード
3. 「ファイル」アプリで zip を展開 → `app-debug.apk`

---

## 2. インストール

1. `app-debug.apk` をタップ
2. 「不明なアプリのインストール」を求められたら、使っているアプリ（Chrome・ファイルなど）に許可を与える
   - 設定 →「アプリ」→「特別なアプリアクセス」→「不明なアプリのインストール」からも変更できる
3. インストール → 開く

> 開発用の署名なので、Play ストア経由のアプリとは別物として扱われる。
> 同じ端末に Play 版が入る予定なら、先にこの開発版を削除してから入れ直すこと。

## 3. 確認してほしいこと

### 基本

- [ ] チャンネルURL（例 `https://www.youtube.com/@NASA`）を入れて「動画を取得」→ **古い順**で一覧が出る
- [ ] 進捗（視聴済み数・％・バー）と「次に見る／続きから」が出る
- [ ] 並び替え（古い順／新しい順）と表示（すべて／未視聴のみ／視聴済みのみ）が効く
- [ ] 行をタップ → 再生画面。**公式プレイヤーで実際に再生できる**
- [ ] 行を**長押し**でスキップの切り替え、右端のチェックで視聴済みの切り替え

### 再生まわり（重点）

- [ ] 途中で戻ってからもう一度開くと、**止めた位置から**再生される
- [ ] 「最初から」で頭に戻る
- [ ] 移動ボタン 5つ（最初へ／前へ／戻す／次へ／最後へ）が効く。**「戻す」で直前の動画と位置に戻る**
- [ ] 自動再生トグルが**初期状態でオフ**。オフのままなら終了後に停止し「次の動画を再生」が出る
- [ ] オンにすると、終了後に**一覧の次の動画**へ進む（YouTube のおすすめには行かない）
- [ ] リピート（右上）で オフ → 1本 → ALL と切り替わり、1本リピートは同じ動画を繰り返す
- [ ] 「未視聴のみ再生」をオンにすると、自動再生が視聴済みを飛ばす
- [ ] 再生設定（右上のつまみアイコン）で速度・字幕が変えられる
- [ ] **ホームに戻ると再生が止まる**（バックグラウンド再生をしていないこと）
- [ ] 再生中は画面が自動で暗くならない。一時停止すると通常どおり暗くなる

### 共有から開く（Android では直接開く）

- [ ] YouTube アプリで動画を開く → 共有 → 一覧から **Channel Timeline Viewer** を選ぶ
- [ ] アプリが開き、**その動画を投稿したチャンネル**の一覧が古い順で表示される
- [ ] チャンネルページを共有した場合も同じように開ける

### 言語

- [ ] 端末の言語を変えると表示も変わる（日本語・英語・中国語・スペイン語・ドイツ語・フランス語・韓国語）

## 4. うまくいかないときの見分け方

| 症状 | 見るところ |
| --- | --- |
| 「APIキーが設定されていません」 | Secret `YOUTUBE_API_KEY_ANDROID` が未登録の APK。手順0を実施して Android Build を回し直す |
| 一覧の取得でエラー | キーの制限（パッケージ名・SHA-1）が合っているか。制限を直した直後は反映に数分かかる |
| 動画が再生されない | 投稿者が外部再生を禁止している動画かもしれない。「YouTubeで開く」で確認 |
| 共有しても出てこない | 共有シートの「その他」から探す。1回使うと上位に出るようになる |
