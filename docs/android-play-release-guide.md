# Google Play へ申請する手順（Channel Timeline Viewer）

内部テストで動作確認済みのものを、**製品版（本番）として世界に公開する**ための手順。
7言語（日本語・英語・簡体中文・スペイン語・ドイツ語・フランス語・韓国語）で申請する。

---

## こちらで用意済みのもの

| 項目 | 置き場所 | 状態 |
| --- | --- | --- |
| ストア掲載情報（7言語） | [`PlayStore/listing/`](PlayStore/listing/) | アプリ名30字・短い説明80字・詳しい説明4000字、すべて上限内 |
| アプリアイコン 512×512 | [`PlayStore/graphics/icon-512.png`](PlayStore/graphics/icon-512.png) | 済み |
| フィーチャーグラフィック 1024×500 | [`PlayStore/graphics/feature-1024x500.png`](PlayStore/graphics/feature-1024x500.png) | 済み（Play では必須） |
| スクリーンショット | [`PlayStore/screenshots/<ロケール>/`](PlayStore/screenshots/) | **7言語 × 4枚**（720×1376。素材は NASA＝パブリックドメイン） |
| 署名付き AAB のビルド | [`android-release.yml`](../.github/workflows/android-release.yml) | 済み（アップロード鍵は Secrets） |

原本を直したら再生成する:

```
python scripts/build_play_metadata.py     # 掲載情報
python scripts/make_play_graphics.py      # アイコン・フィーチャーグラフィック
python scripts/capture_play_screenshots.py  # スクショ（実機をつないで実行）
```

## Play Console でやること

### 1. ストア掲載情報（7言語）

**メインのストアの掲載情報** → 言語を追加（ja-JP / en-US / zh-CN / es-ES / de-DE / fr-FR / ko-KR）。
各言語で [`PlayStore/listing/<ロケール>.md`](PlayStore/listing/) の内容を貼り付ける。

| 入力欄 | 貼るもの |
| --- | --- |
| アプリ名 | `Channel Timeline Viewer`（全言語共通） |
| 短い説明 | 各言語の「短い説明」 |
| 詳しい説明 | 各言語の「詳しい説明」 |
| アプリアイコン | `graphics/icon-512.png` |
| フィーチャーグラフィック | `graphics/feature-1024x500.png` |
| スマートフォンのスクリーンショット | `screenshots/<ロケール>/` の4枚 |

### 2. アプリのカテゴリと連絡先

| 項目 | 値 |
| --- | --- |
| アプリまたはゲーム | アプリ |
| カテゴリ | **教育**（iOS 版と揃える） |
| メール | `support@jewelrysunflower.com` |
| ウェブサイト | `https://channeltimeline.jewelrysunflower.com/` |
| プライバシーポリシー | `https://channeltimeline.jewelrysunflower.com/en/privacy/` |

### 3. データセーフティ（iOS の「App のプライバシー」に相当）

**「データを収集していません」**で申告する。根拠:

- アカウントなし・当方のサーバーなし
- 視聴済み／スキップ・進捗・お気に入り・メモ・再生位置・一覧キャッシュは**すべて端末内**に保存し、外部送信しない
- 解析 SDK・広告 SDK は不使用、広告IDも使わない

質問への答え:

| 質問 | 回答 |
| --- | --- |
| アプリはユーザーデータを収集または共有しますか | **いいえ** |
| データは転送中に暗号化されますか | （収集しないので回答不要。聞かれたら「はい」＝API通信はHTTPS） |
| ユーザーはデータの削除をリクエストできますか | アプリを削除すれば全消去。該当欄があればその旨を記載 |

> 再生時は YouTube 公式の埋め込みプレイヤーを表示するため、YouTube／Google 側が自社ポリシーに基づき
> 情報を取得することがある。これは当方が組み込んだ SDK による収集ではなく、プライバシーポリシーに明記済み。

### 4. コンテンツのレーティング（アンケート）

| 質問 | 回答 |
| --- | --- |
| カテゴリ | ユーティリティ／その他（または教育） |
| 暴力・性的表現・不適切な表現・薬物 | いずれも **なし** |
| ユーザー同士のやり取り（チャット等） | **なし** |
| 位置情報の共有 | **なし** |
| 個人情報の共有 | **なし** |
| デジタル購入 | **なし** |
| **ユーザーが生成したコンテンツを表示するか** | **はい**（YouTube の動画を表示するため）。フィルタ機能の有無を聞かれたら「YouTube 側の年齢制限・再生制限がそのまま適用される」と回答 |
| アプリはウェブブラウザまたは検索エンジンですか | **いいえ**（WebView は公式プレイヤーの表示専用で、任意のURLを開く機能はない） |
| アプリは主にニュースまたは教育商品ですか | **いいえ**（アプリ自身は教材やニュースを配信していない。ストアのカテゴリ「教育」とは別の質問） |
| IARC の利用規約 | 同意が必須（法的な同意なので本人が操作する） |

### 5. 広告

**「このアプリには広告が含まれていません」** を選ぶ。
※ 動画再生中に YouTube 側の広告が出るが、これは公式プレイヤーが配信するもので、アプリが広告を組み込んでいるわけではない。
迷う場合は「含まれていません」で申告し、審査で指摘があれば説明する（アプリ内に広告SDKは一切ない）。

### 5-2. 「アプリのコンテンツ」の残りの申告

Play Console → **ポリシー → アプリのコンテンツ** に並ぶ項目。上から順に答える。

| 項目 | 回答 |
| --- | --- |
| プライバシー ポリシー | `https://channeltimeline.jewelrysunflower.com/en/privacy/` |
| ログインの詳細（アプリの一部にアクセス制限がありますか） | **いいえ**。アカウントもログインも無く、全機能が起動直後から使える。アプリ内に支払いの必要なコンテンツもない（Pro は Play ストアでの購入であって、アプリ内のアクセス制限ではない） |
| 行政アプリ | **いいえ** |
| 金融取引機能 | **いいえ**（決済・送金・投資・保険・暗号資産の機能はない） |
| 健康 | **いいえ**（医療・フィットネス・メンタルヘルスの機能はなく、健康関連の研究にも当たらない） |

### 5-3. ストアの掲載情報に表示する連絡先

**公開される**情報。メールアドレスだけが必須。

| 項目 | 値 |
| --- | --- |
| メールアドレス | `support@jewelrysunflower.com` |
| 電話番号 | **空欄**（公開されるため入れない。アカウント側の非公開の電話番号とは別物） |
| ウェブサイト | `https://channeltimeline.jewelrysunflower.com/` |

`python scripts/play_publish.py --mode details` で API から入れられる（画面入力は不要）。

### 5-4. 外部マーケティング

**オンのまま**でよい。Google が Play の外（YouTube や提携先の枠）でアプリを紹介することがある設定で、
こちらに費用は発生しない。無料の露出を捨てる理由がない。

### 6. 対象ユーザーと年齢

| 項目 | 値 |
| --- | --- |
| 対象年齢層 | 13歳以上（子ども向けではない） |
| 「子ども向け」設定 | **いいえ** |

> 「親が小さい子に見せる」使い方を想定していても、**申告は13歳以上のままにする**。
> 13歳未満を1つでも選ぶとファミリー向けポリシーの対象になり、
> 「表示するコンテンツがすべて子どもに適切であること」「広告は認定済みSDKのみ」が必須になる。
> 本アプリが表示するのはユーザーが指定した任意の YouTube チャンネルで、
> 再生中の広告も公式プレイヤーが配信するものなので、この要件は満たせない。
> YouTube API 側でも、子ども向けクライアントは COPPA/GDPR 適合と Google への申告が要る。
> アプリを操作するのは**親**、という整理で13歳以上が正しい申告になる。
> ストア文言・スクリーンショットで子どもを訴求しないこと（実質子ども向けと判断されるため）。

### 7. 国と地域・価格（**本体無料＋Pro 買い切り**）

- アプリ本体の価格: **無料**
- アプリ内課金: **あり**。買い切りの `pro_unlock`（複数チャンネル保存の解放）
- サブスクリプション: **なし**
- 国と地域: **すべて選択**（iOS と同じ方針。EU 向けにはトレーダー情報が必要で、これは Apple 側とは別に Play でも求められる場合がある）

> **本体を無料にすると、二度と本体有料アプリには戻せない**（Play は無料→有料の変更を許さない）。
> 今回はその前提で「本体無料＋Pro 買い切り」に決めている。値付けは Pro 側で行い、
> 価格はアプリのコードに持たせていないので、Play Console から変更できる。

商品の作成手順・テスト購入・プロモーションコードは
[`android-iap-pro.md`](android-iap-pro.md) にまとめてある。

### 8. リリース

1. GitHub → Actions → **Android Release** を実行
   - `version_name`: `1.0`
   - `upload_to_play`: **オフ**（既定。手でアップロードする）
   - 完了したら artifact **`android-release`** の `app-release.aab` をダウンロード

   > 自動アップロードを使いたい場合は、先に
   > [`android-play-service-account.md`](android-play-service-account.md) の手順で
   > サービスアカウントを作る（**このアカウントにはまだ存在しない。新規作成が必要**）。
   > 初回リリースは Play の API では送れないため、どちらにせよ最初は手動になる。
2. Play Console → **製品版** → 新しいリリースを作成 → AAB を選択
3. リリースノート（各言語）を入力 → 「リリースのレビュー」→ **審査に送信**

初回審査は数日かかることがある（内部テストと違い本番審査が入る）。

## 審査で説明を求められたときの材料

`docs/AppStore/review-notes-en.md`（英語）と同じ内容がそのまま使える。要点:

- 一覧の取得は **YouTube Data API v3** のみ。スクレイピングなし
- 再生は **公式 IFrame Player**。ダウンロード・独自プレイヤー・広告回避なし
- 自動再生は**既定オフ**で、進むのは開いている一覧の次の動画だけ
- バックグラウンド再生なし（再生中だけ画面を消さないだけ）
- アプリ内購入・サブスク・広告なし
- 視聴履歴などは端末内のみ
