# 実画面確認チェックリスト（Mac / Xcode / 実機・シミュレーター）

GitHub Actions ではコンパイルとユニットテストまで確認済み。ここでは **実際の画面操作**を Mac/Xcode で確認する。
Windows では確認できない「見た目・操作・実再生」を埋めるためのもの。

## 事前準備
- [ ] Mac で `brew install xcodegen`
- [ ] リポジトリ取得後、`xcodegen generate` → `ChannelTimelineViewer.xcodeproj` が生成される
- [ ] `Resources/Config.plist` を作成し、実際の `YOUTUBE_API_KEY` を設定（[`app-store-preparation.md`](app-store-preparation.md) 参照）
- [ ] Xcode でプロジェクトを開き、ターゲット `ChannelTimelineViewer` をシミュレーター（iPhone 15等）で実行（Cmd+R）
  - ※ シミュレーターなら署名・Apple Developer 登録は不要

---

## 1. ホーム画面（ChannelInputView）
- [ ] アプリ名・チャンネルURL入力欄が表示される
- [ ] 右上に「ⓘ」ボタンがある → タップで「このアプリについて」が開く
- [ ] APIキー未設定時：「APIキーが設定されていません」の警告が出る（Config.plist 未作成で確認）
- [ ] 画面下部に注意事項（公式アプリではない等）が表示される
- [ ] チャンネルURL（`@handle` / `/channel/UC...`）を入力して「動画を取得」→ 一覧画面へ遷移する
- [ ] 不正なURLや存在しないチャンネルで、日本語のエラーメッセージが出る

## 2. このアプリについて（AboutView）
- [ ] アプリ名・用途説明が出る
- [ ] 注意事項が **5点**表示される（公式でない／公式埋め込み／DLしない／広告回避しない／BG再生しない）
- [ ] `Config.plist` に `PRIVACY_POLICY_URL` を設定した場合、プライバシーポリシーのリンクが出てタップで開く
- [ ] 「閉じる」で戻れる

## 3. 動画一覧画面（VideoListView）
- [ ] チャンネル名がタイトルに出る
- [ ] **進捗バー**と「X / Y本 視聴済み（Z%）」が表示される
- [ ] **「次に見る：第N本目」**（または「続きから：第N本目」）が目立つ位置に表示され、タップで再生画面へ
- [ ] 右上のフィルターメニューで：
  - [ ] 並び替え「古い順 / 新しい順」が切り替わり、リスト順が変わる
  - [ ] 表示「すべて / 未視聴のみ / 視聴済みのみ」が切り替わり、リストが絞り込まれる
- [ ] ヘッダーに「N本表示 / 全M本」が出る
- [ ] 各行にサムネ・タイトル・公開日・（視聴済みなら）緑チェックが出る
- [ ] すべて視聴済みにすると「すべて視聴済みです 🎉」になる

## 4. 再生画面（PlayerView）
- [ ] YouTube 公式埋め込みプレイヤーが表示され、再生できる
- [ ] 「前へ / 次へ」で動画が切り替わる（端で無効化される）
- [ ] 主操作エリアに「**自動再生オフ：終了後に停止**」トグルが**常に**表示されている
      （「視聴済みにする」の大きなボタンは**無い**）
- [ ] 右上「…」メニューから「視聴済みにする / 視聴済みを解除」ができ、一覧の緑チェック・進捗に反映される
- [ ] 動画一覧を**右スワイプ**しても視聴済み / 未視聴を切り替えられる
- [ ] **メモ欄**に日本語入力でき、画面遷移して戻っても保存されている（別動画では別メモ）
- [ ] メモ欄をタップして入力中に、**キーボード上の「完了」**を押すと入力が終わる
- [ ] メモ欄以外（余白・タイトル付近など）を**タップしても入力が終わる**
- [ ] 画面を**下にスワイプ**してもキーボードが下がる（入力内容は消えない）
- [ ] 「YouTubeで開く」で公式アプリ/サイトが開く（「…」メニューからも開ける）
- [ ] **初期状態では**再生終了時に停止し、「次の動画を再生」ボタンが表示される（自動では進まない）
- [ ] トグルをオンにすると表示が「**自動再生オン：終了後に次の動画へ**」に変わり、
      終了時に一覧の次の動画が続けて再生される（関連動画には行かない）
- [ ] 終了して自動で次に進んだとき、**実際に見た動画だけ**が視聴済みになる（1本飛ばされない）
- [ ] 画面**右上のリピートバッジ**（設定アイコンの左）を押すたびに
      **オフ（枠線だけ）→ 1本（緑地に「1」）→ 全体（緑地に「ALL」）→ オフ** と切り替わる
- [ ] 3つの状態が一目で見分けられる（ダークモードでも枠線が見える）
- [ ] **リピート「1本」**：終了すると同じ動画が最初から再生され、何度でも繰り返す
      （自動再生がオフでも繰り返す）
- [ ] **リピート「全体」**：自動再生オンで最後の動画が終わると、先頭の動画に戻る
- [ ] **リピート「オフ」**：最後の動画で止まる
- [ ] リピートの状態はアプリを再起動しても保持される
- [ ] **未視聴のみ再生**：オンにすると、自動再生で視聴済みの動画を飛ばして未視聴だけ再生する
- [ ] **スキップ**：一覧を左スワイプ、または再生画面の「…」→「スキップにする」で設定でき、
      一覧の行に**オレンジのチェック**（緑＝視聴済みの下）が付く
- [ ] スキップした動画は自動再生で飛ばされる（手動の「次へ」では普通に開ける）
- [ ] スキップした動画は「次に見る／続きから」の候補にならない
- [ ] 途中まで見て別画面へ移動 →もう一度同じ動画を開くと**続きから再生**され、
      「前回の続き（m:ss）から再生中」が表示される
- [ ] 「最初から」ボタン（または「…」メニューの「最初から再生」）で先頭に戻り、案内が消える
- [ ] 「…」メニューの「続きから再生する」をオフにすると、常に最初から再生される
- [ ] 最後まで見た動画は、次に開くと最初から再生される（見終わった位置は残らない）
- [ ] 設定（自動再生 / 続きから）はアプリを再起動しても保持される
- [ ] 画面上部と動画タイトルの下に、**再生中のチャンネル名**が表示される
- [ ] タイトルの下に「公開日（1,034 / 3,500）」のように**一覧内の位置**が出る
- [ ] 移動ボタンが **[最初へ / 前へ / 戻す / 次へ / 最後へ]** の5つで、端では自動的にグレーになる
- [ ] 「最初へ」などを押し間違えた直後に **「戻す」で元の動画・再生位置に復帰**する
      （「続きから再生」をオフにしていても位置が戻る）
- [ ] **字幕（CC）がオフの状態で再生が始まる**。プレイヤーの字幕ボタンから手動で出せる
- [ ] プレイヤーは常に 16:9 のままで、レイアウトが崩れない（拡大縮小の機能は持たない）
- [ ] 公式プレイヤーの歯車を開くと、メニューが**下端から上へ伸びて**
      「速度／字幕／その他のオプション」が 16:9 の中に収まって表示される
- [ ] 再生画面の「再生設定」行に**現在の状態**（例: 速度 1倍・字幕 オフ）が出る
- [ ] その行、または右上のスライダーアイコンから **再生設定シート**が開く
- [ ] シートで速度を変えると実際に再生速度が変わり、行の表示も変わる
- [ ] シートで字幕のオン／オフ・トラック切り替えができる
      （再生開始後に開くとトラックが出る。シートを開くたびに一覧を取り直す）
- [ ] 画質を変えたいときは、公式プレイヤーの**全画面ボタン → 歯車 → 画質**で選べる
- [ ] **一度も触っていない状態でアプリを更新しても、自動再生が勝手にオンにならない**

## 4-2. 一覧の読み込み（キャッシュ）
- [ ] 初回は「動画を取得中...」で全件取得される（本数が多いほど時間がかかる）
- [ ] 一度開いたチャンネルを開き直すと、**待たされずにすぐ一覧が出る**
- [ ] そのとき「保存済みの一覧を表示中（最終更新 …）」または「新着を確認中…」が出る
- [ ] 新しい動画が投稿されていれば、少し待つと一覧の末尾（新しい順なら先頭）に追加される
- [ ] 一覧を**引き下げる**と新着を確認できる（全件取り直しにはならない＝速い）
- [ ] 右上メニューの「すべて再読み込み」で全件取り直しができる
- [ ] アプリを再起動しても、保存済みの一覧が使われる

## 5. 進捗・続きから（横断）
- [ ] 動画を何本か視聴済みにし、ホームに戻ると、お気に入りのチャンネル行に進捗バーと「続きから見る」が出る
- [ ] チャンネルを再度開くと「続きから：第N本目」が前回の続き（最後に開いた未視聴 or 最古未視聴）を指す
- [ ] 「未視聴のみ」フィルターで、次に見るべき動画が探しやすい

## 6. お気に入り（複数チャンネル）
- [ ] 複数チャンネルを取得すると、ホームに最近使った順で複数並ぶ
- [ ] 各チャンネルに進捗率が出る
- [ ] スワイプ（または編集）でチャンネルを削除でき、進捗も消える

## 7. 規約順守の目視確認
- [ ] 動画は必ず公式プレイヤー内で再生される（独自プレイヤー化していない）
- [ ] ダウンロードボタン等が無い
- [ ] バックグラウンド（ホームに戻る/画面ロック）で音声が止まる（BG再生していない）
- [ ] **再生中は画面が自動で暗くならない**（置いたままでも止まらない）
- [ ] 一時停止すると通常どおり画面が暗くなる／再生画面を離れても元に戻る
- [ ] 自動再生は**初期状態でオフ**（ユーザーが自分でオンにしない限り連続再生しない）
- [ ] 自動再生をオンにしても、ホームに戻ると再生・自動送りが止まる（裏で再生し続けない）
- [ ] 自動再生で進む先が「一覧の次の動画」だけで、YouTube のおすすめ動画に飛ばない

---

## 不具合があった場合
- 画面・操作の不具合は Xcode のコンソールログを確認 → 内容を共有いただければ修正します。
- ロジック（計算・保存）はユニットテストで担保済みなので、UI配線/表示まわりが中心の想定。
