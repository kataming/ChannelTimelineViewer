# 収益化方針（Monetization Plan）

> **確定方針**（2026-08-18）。アプリ内課金・サブスクリプション・広告はいずれも採用せず、
> **アプリ本体の価格**だけで収益化する。実装作業は不要（StoreKit のコードは書かない）。

## 採用しないもの

| 手段 | 採否 | 理由・補足 |
|---|---|---|
| アプリ内課金（Premium / Pro） | **採用しない** | 無料版と有料版で機能差を作らない方針のため |
| サブスクリプション | **採用しない** | 同上。継続課金の運用コストも見合わない |
| 広告 | **採用しない** | 公式プレイヤーの体験に広告を絡めない。SDK も入れない |
| $0.99 の価格帯 | **採用しない** | 価格は $4.99 / $9.99 の段階のみを使う |

そのため次の実装は**行わない**。

- StoreKit のコード（`StoreKit` の import、購入・復元・レシート処理）
- App Store Connect の **IAP Product ID の作成**
- 無料版／有料版の出し分け（機能ゲート、上限、フラグ）

## 採用する形：本体価格の段階的な引き上げ

初回公開は **無料（$0）**。その後、実績を見ながら **$4.99 → $9.99** と本体価格を上げる。

> **重要（既存ユーザーの扱い）**
> 無料期間中に入手したユーザーには、**後から機能制限をかけない**。
> App Store の仕組み上、一度入手したアプリはその後値上げされても引き続き使えるため、
> 「無料で入れた人はそのまま全機能を使える」状態を維持する。
> これは「後出しで有料化して機能を削る」ことをしない、という約束でもある。

### 値上げの目安

#### $0 → $4.99

| 指標 | 最低ライン | 理想 |
|---|---|---|
| 累計ダウンロード | 1,000 以上 | 3,000〜5,000 |
| 評価件数 | 20 件以上 | 30〜50 件以上 |
| 平均評価 | 4.5 以上 | 〃 |

加えて、次がすべて満たされていること。

- 重大バグがない
- **共有シート（Share Extension）** が安定して動く
- **YouTube 再生**（公式埋め込みプレイヤー）が安定している
- **続きから再生**が意図どおり動く
- **進捗の保存**（視聴済み・進捗率・メモ）が失われない

#### $4.99 → $9.99

| 指標 | 最低ライン | 判断 |
|---|---|---|
| $4.99 での有料購入 | 100 件以上 | 300 件以上なら値上げを**強く検討** |
| 合計評価件数 | 50 件以上 | |
| 平均評価 | 4.6 以上 | |

加えて、**有料化後に低評価・返金・価格への不満が目立っていない**こと。

## 変わらない前提（規約順守）

価格に関わらず、次は**提供しない**。有料にしたからといって解禁はしない。

- 動画のダウンロード / オフライン保存
- バックグラウンド再生
- 広告の回避・スキップ
- YouTube の再生制限・UI の回避

本アプリの対価は「**チャンネル動画を公開日順に整理し、視聴の進捗を管理できること**」に対するものであり、
YouTube のコンテンツや再生体験を売るものではない。

## 初めて有料にする前に必要な手続き（2026-08-18 追記）

無料のうちは不要だが、**1円でも価格を付けるなら先に済ませておく**必要がある。反映に数日かかることがある。

| 手続き | 場所 | 備考 |
|---|---|---|
| 有料アプリ契約（Paid Apps Agreement）の署名 | App Store Connect → ビジネス → 契約 | 2026-08-18 時点で「新規（未署名）」。無料アプリ契約は有効 |
| 銀行口座（振込先）の登録 | 同 → お支払いと財務レポート | 法人口座（JEWELRY SUNFLOWER, K.K.） |
| 税務情報の登録 | 同 | 日本の情報 ＋ 米国向け W-8BEN-E など |

- **使用許諾契約は標準のままでよい**（有料かどうかとは関係ない。カスタムEULAが要るのは独自規約に同意させる場合）。
- 有料化しても **アプリ内課金・サブスクは入れない**方針は変わらないため、ストア説明文の
  「アプリ内課金・サブスクリプションはありません」はそのまま正しい。
- 買い切りなので、**無料期間に入手した人は値上げ後もそのまま使える**（機能制限も追加しない）。

## 値上げのときにやること

1. App Store Connect の「価格および配信状況」で価格を変更する（アプリの再提出は不要）
2. 本ドキュメントの履歴に、変更日・変更前後の価格・そのときの実績（DL数・評価）を追記する
3. [`app-store-connect-fields.md`](app-store-connect-fields.md) の価格欄を更新する
4. 説明文（[`app-store-description.md`](app-store-description.md)）に価格を書いている箇所があれば直す
